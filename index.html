Using themes on iPhone or iPad

Export opens the share sheet when file sharing is supported. Choose Paperback if it appears, or Save to Files. Choose Download file if you prefer a download. If sharing is unavailable, Export downloads the file instead.

In Safari, open Downloads to find your file. In Files, locate the .pbcolors file, touch and hold it, then choose Share. Look for Paperback, including under More. If it is not listed, use Paperback's theme import option if your version provides one. Keep the .pbcolors extension.

To edit a saved theme here, choose Import theme and browse to the file. A saved draft is browser storage, not a file in Files.
